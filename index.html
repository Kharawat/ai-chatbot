Real AI Chatbot

A full-stack chatbot with secure API handling, local chat history, and real model responses.

Checking server

How it works

Frontend + Backend

The browser sends messages to a Node server. The server calls the OpenAI API and keeps the API key hidden.

Safety

No API key in frontend

The API key lives in `.env` on the server only. This keeps the public code safe for GitHub.

Storage

Local history

Chat history is saved in this browser with localStorage and can be cleared any time.
